🎯 DÉPLOIEMENT RAPIDE (10 MINUTES):

1️⃣  Accéder au serveur:
    ssh erpgmc@10.0.5.18        (Mot de passe: toor)
    su                           (Mot de passe: 20ERP@GMC2024)

2️⃣  Installer Docker:
    curl -fsSL https://get.docker.com | sh
    apt-get install -y docker-compose
    usermod -aG docker erpgmc

3️⃣  Cloner le projet:
    mkdir -p /srv/sgdra
    cd /srv/sgdra
    git clone <votre-repo> . 
    # ou copier les fichiers manuellement

4️⃣  Configurer l'environnement:
    cp .env.production .env.production.local
    nano .env.production.local     # Adapter les variables
    chmod +x deploy.sh pre-check.sh

5️⃣  Vérifier la configuration:
    ./pre-check.sh                # Doit retourner "ready for deployment"

6️⃣  Déployer:
    ./deploy.sh start
    ./deploy.sh health             # Vérifier que tout fonctionne
    ./deploy.sh status             # Voir le statut des services

🔧 COMMANDES PRINCIPALES:

./deploy.sh start        ─ Démarrer tous les services
./deploy.sh stop         ─ Arrêter tous les services
./deploy.sh restart      ─ Redémarrer tous les services
./deploy.sh status       ─ Afficher le statut des services
./deploy.sh health       ─ Exécuter les vérifications de santé
./deploy.sh logs         ─ Afficher les logs en temps réel
./deploy.sh logs backend ─ Logs du service backend uniquement
./deploy.sh backup       ─ Créer une sauvegarde complète
./deploy.sh update       ─ Mettre à jour le code et redéployer

🔐 CERTIFICATS SSL:

Auto-signés (développement):
  → Générés automatiquement au démarrage
  → Valides 365 jours
  → Accepter les warnings du navigateur

Let's Encrypt (PRODUCTION - RECOMMANDÉ):
  1. sudo apt-get install certbot
  2. sudo certbot certonly --standalone -d yourdomain.com
  3. sudo cp /etc/letsencrypt/live/yourdomain.com/fullchain.pem frontend/ssl/cert.pem
  4. sudo cp /etc/letsencrypt/live/yourdomain.com/privkey.pem frontend/ssl/key.pem
  5. ./deploy.sh restart

Renouvellement automatique:
  → Ajouter cron job pour certbot renew
  → Redémarrer Nginx après renouvellement
