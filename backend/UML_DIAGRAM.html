📌 Structures Principales

Classes Implémentées

  • User - Authentification (AGENT/ADMIN)
  • Document - Entité centrale (NOUVEAU→VALIDE→ARCHIVE)
  • DocumentSpecification - Configuration par type
  • DocumentValidationResult - Résultats validation
  • Folder - Hiérarchique (parent-child)
  • RoutingRule - Auto-routing (JSON conditions)
  • Notification - Auto via signals
  • DepartmentDocumentType - Contraintes métier

Relations Principales

  • User creates Document (1:N)
  • User creates Folder (1:N)
  • Folder contains Document (1:N)
  • Folder parent-child Folder (N:N)
  • Document validates DocumentValidationResult (1:1)
  • Document triggers Notification (1:N)
  • RoutingRule configures Folder (N:1)
