❌ IF YOU DON'T SEE MESSAGE IN CONSOLE:

Issue 1: WebSocket not connected?
   → Check: Is backend running?
   → Check: Is Redis running? (redis-cli ping)
   → Check: Browser console for connection errors

Issue 2: Not receiving "notification" type?
   → Possible message went to wrong group
   → Check backend logs for broadcast message

Issue 3: Notification in DB but not in real-time?
   → Signal might not be triggered
   → Check: Is apps.common.signals imported?
   → Check: Is apps.notifications.signals imported?

📊 TEST WITH MULTIPLE NOTIFICATIONS:

In Django shell:

from django.contrib.auth import get_user_model
from apps.notifications.models import Notification

admin = get_user_model().objects.get(matricule='TESTADMIN')

for i in range(3):
    Notification.objects.create(
        recipient=admin,
        notification_type='DOCUMENT_UPLOADED',
        title=f'Test Notification {i+1}',
        message=f'This is test {i+1}',
        is_read=False
    )
    print(f'Created notification {i+1}')

Expected in browser:
   ✅ 3 messages: Message reçu: notification
   ✅ 3 notifications appear in UI
   ✅ All instantly!
